# Smoke-тест веб-панели

Проверяет отрисовку панели без браузера: загружает `web/index.html` и `web/app.js`
в jsdom c подменёнными `fetch`, `WebSocket` и библиотекой графиков, отдаёт тестовое
состояние бота и убеждается, что все блоки (карточки, таблицы, формы, журнал, вкладки)
заполняются без ошибок.

```bash
cd tests/panel
npm init -y && npm i jsdom
node panel.smoke.js ../../web
```
